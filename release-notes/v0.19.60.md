# Proma v0.19.60 更新

本版本为自托管仓库构建版本，仅提供 Windows x64 安装包。

## Bug 修复

- **Cua Driver 检查更新误报失败** — 修复官方安装器已成功替换二进制、但因陈旧 daemon（进程存活但命名管道不响应）返回非零退出码时，Proma 误判为"更新失败"且界面版本号停留在旧值的问题。现在安装命令返回错误后会复核磁盘上的实际版本：若已达到目标版本，即判定更新成功并在结果中提示需重启 daemon；同时补充了覆盖该场景的单元测试。

## 下载

- **Windows x64** — `Proma-Setup-0.19.60.exe`
