# Proma v0.19.59 更新

## 新功能

- **Cua Driver 更新** — Agent 自动发现 Cua Driver 新版本后主动调用其官方更新命令完成安装；安装全程由官方安装器校验 Sigstore 签名与 SHA256SUMS，确保产物完整可信。镜像源可通过 `CUA_DRIVER_RS_DOWNLOAD_BASE_URL` 配置为就近加速地址。

## 体验优化

- **Computer Use 设置页** — 新增 Computer Use 设置项，展示 Cua Driver 的安装状态、版本与可执行文件路径；支持重新检测与检查更新，并可一键打开 Agent 会话检查安装、服务与权限配置。
